# SlotRecorder — 自動錄製 slot 影片

在 LDPlayer 模擬器裡自動開 app → 進指定 slot → 調最低押注（讀畫面確認）→ 連續 spin → 錄影 N 分鐘 → 自動產出統計。
彈窗、廣告、閃退、金幣用完都會自己處理；**可以多台模擬器同時錄**。執行時不需要 AI。

## 第一次安裝（每台電腦一次）
1. **Python 不用自己裝**：`install.bat` 找不到 Python 3.10~3.12 時會自動安裝 3.12（先用 winget；不行就從 python.org 下載官方安裝檔，裝進 `SlotRecorder\python\`，不用管理員權限）。需要網路。
   - 已經有 3.13 以上也沒關係，會另外裝一份 3.12 給這個工具用。
2. 安裝 **LDPlayer 9 / 14**，每台模擬器設定：進階設定 → 解析度 **1280×720**、DPI **240**
   - 在第一台模擬器裡安裝要錄的 app，先手動開一次、更新到最新版
3. 雙擊 **`install.bat`**（自動安裝 Python、套件、scrcpy、ffmpeg，約 2~5 分鐘；視窗訊息是英文，最後出現 `Tool check: all found` 就是成功）
4. 雙擊 **`run.bat`** → 選模擬器 → 按 **準備模擬器**（自動打開 ADB 本地連接、開機、從別台複製 app）→ 按 **環境檢查**，全部 ✔ 就可以用
   - LDPlayer 不在 `D:\LDPlayer\LDPlayer14` → 按 **設定** 修改

## 日常使用
1. `run.bat` → 選 **App** 和 **模擬器** → 在 Slot 清單 **雙擊「錄」欄** 勾選（雙擊「分鐘」改長度）
2. 按 **▶ 開始錄製**（模擬器沒開會自動開機）。錄製期間不要操作那台模擬器
3. **大量同款樣本：台數 × 長度 × 重複，自己決定** → ▶ 旁設「同時用 __ 台」和「重複 __ 次」。這 N 台會**各錄一份完整長度影片**（不是把時間切開），
   重複 R 次 → 每款得到 **N×R 支影片**，全部**合併成一份統計報告** `G<日期時間>_名稱_merged_summary.html`（樣本越多越準；每支影片也各有自己的統計）。
   例：勾一款、每款 60 分鐘、同時 3 台、重複 5 次 → 15 支一小時影片、約 5 小時收齊。現有模擬器不夠時會自動新建 `SR_` 模擬器、複製 app、用新帳號開始
   （88F 新帳號要先練到約 5 級，會晚 15~40 分鐘才開錄）。重複期間同一批模擬器一直開著，全部錄完才關閉新建的 `SR_` 台（保留，下次優先再用）
4. 要讓不同台錄不同遊戲：上方換一台模擬器（和 App / slot），「同時用」設 1、「重複」設 1，再按一次 ▶。每台在「錄製工作」表格各佔一列
5. **夠準就停**（▶ 旁的勾選框）：不照分鐘數錄，每款錄到 RTP 95% 範圍 ±10 個百分點為止（含之前錄過的局數、多台一起錄的局數），
   每款最多 240 分鐘（設定可改）。波動大的遊戲常常要上萬局才夠準，所以很多款會錄到上限才停，報告會照實寫範圍
6. 影片在 `videos\<app>\日期_名稱.mp4`，多台一起錄的檔名後面多 `_e<模擬器編號>`（按 **開啟影片資料夾**）

| 按鈕 | 作用 |
|---|---|
| ⏰ 定時開始 | 輸入時間（例 22:30），時間到自動開模擬器開錄。**GUI 視窗要開著**（可縮小） |
| ■ 停止此台 / 全部停止 | 已錄的部分會存好再結束（通常 10~30 秒，最多約 1 分鐘）。對「排程中」的列按停止 = 取消排程 |
| ↻ 接續上次 | 這台模擬器上次中斷 / 停止的工作，從沒完成的 slot 繼續 |
| 📊 分析影片 | 選舊影片補算統計（錄完的影片會自動算）。**多選同一款的幾支影片 → 另外產生一份合併報告** |
| 📋 總覽 | 所有錄過的遊戲一頁看完：影片時數、局數、RTP（95% 範圍）、還差幾局到目標。同時更新 Excel 與 PDF |
| 勾選樣本不足（清單上方） | 把「錄過但局數不到目標」的遊戲勾起來，分鐘數設成預估補足所需（其他取消勾選），再按 ▶ 補錄 |
| 📖 賠率表（清單下方） | 選一款遊戲：已截過 → 開資料夾；沒截過 / 要重截 → 在目前的模擬器進遊戲截圖 |
| 打包帶走 | 產生 `SlotRecorder_日期.zip`（不含影片、log、本機設定），帶到別台電腦用 |

**當機 / 重開機**：GUI 開啟時若發現上次的錄製被中斷（不是你按停止的），會倒數 60 秒後自動接續（可取消）。
設定 → 勾選「開機登入 Windows 後自動開啟 SlotRecorder」，重開機登入後就會自己開 GUI 並接續。

錄製工作表格會即時顯示：目前第幾款、進度、狀態（遊戲中 / 關彈窗中 / 卡住處理中 / 回大廳重進 / 重置帳號）、已處理彈窗數、非遊戲畫面比例，
以及**即時統計**（每分鐘更新：這段已錄幾局、RTP、95% 範圍、特色次數；括號內是含之前影片的總局數）。即時數字是邊錄邊估，正式數字以錄完的影片分析為準。
開始前會檢查記憶體與硬碟（每台模擬器約需 4~5 GB 記憶體，每小時影片約 1.4 GB；32 GB 的電腦建議最多同時 3~4 台）；錄製中硬碟剩不到 1 GB 會自動停止並保存。

## 每支影片會產生的檔案
| 檔案 | 內容 |
|---|---|
| `名稱.mp4` | 完整影片 |
| `名稱_clean.mp4` | 剪掉「卡住 / 關彈窗超過 20 秒 / 回大廳」片段的版本（原檔保留）|
| `名稱_timeline.csv` | 每段非遊戲畫面的時間、長度、做了什麼、有沒有被剪掉 |
| `名稱_summary.html` | **統計**：遊戲局數、實測 RTP（含 95% 範圍）、中獎率（每 N 把中一次）、贏分倍數分布、每小時輸贏、前 10 大獎的影片時間 |
| `名稱_spins.tsv` | 每一把一列：影片時間、押注、贏分、倍數、餘額 |
| `名稱_stats.json`、`_snaps\` | 錄影紀錄（spin 次數、彈窗、重置）與異常截圖 |

統計的算法（參考 SpookyLink）：讀畫面上的**餘額**，餘額少一注 = 一把，餘額增加 = 這把的贏分（免費遊戲 / 特色遊戲的贏分算在觸發那把）。
關彈窗前後的加錢（每日獎勵、升級禮物）另列「贈送」不算贏分。局數少於 1000 把時 RTP 範圍很寬，僅供參考。

## 總覽、Excel、PDF、賠率表
- `videos\總覽.html`（+ `.pdf`）：每款遊戲累積的時數、局數、RTP、還差多少局（目標在 設定 → 每款目標局數，預設 1000）。每次分析完自動更新
- `videos\<app>\<app>_統計.xlsx`：總表 + 每款一張明細（每一把一列）。RTP、中獎率、贏分分布都是**活的公式**；改總表 S1 的目標局數，「還差局數」會跟著變
  （檔案開在 Excel 時不會被覆蓋，關掉後下次分析會更新）
- 每份 `_summary.html` 旁邊會有同名 `.pdf`（用電腦上的 Edge / Chrome 轉，不用另外裝）
- **特色遊戲（自動偵測）**：某把贏分後超過 25 秒沒扣押注、而且畫面仍在遊戲中 = 一次特色（免費遊戲、Hold & Spin…）。
  報告列出每 N 局觸發一次、平均 / 最大倍數、佔 RTP 多少；每次特色剪成短片 `影片名_features\01_時間_倍數x.mp4`（前後各 5 秒）＋開始 / 結束截圖。
  很長的大獎動畫可能被算進來，整個畫面換成小遊戲的特色可能漏掉，請用片段確認
- 賠率表 / 規則頁：每款遊戲**第一次錄影前**自動點 i 按鈕逐頁截圖一次，存在 `videos\<app>\paytables\<遊戲>\01.jpg…`

## 送進辨識流程（SpookyLink）
錄完 LL 的 **Spooky Link Mo' Mummy** 會自動轉成 SpookyLink 用的格式（574×1022 @30，檔名 `月日時分秒.mp4` + `.ok`），
放進 `Jumbo\SpookyLink\work\canvas\`，接著照 SpookyLink 的流程跑掃描即可。那台電腦沒有 SpookyLink 資料夾就自動略過。
手動補轉：`python -m core.exports <影片.mp4>`。要接其他專案，在 `config.json` 加 `exports` 設定（格式見 `core\exports.py`）。

## 遊戲清單
Slot 清單已經內建兩個 app 大廳裡的遊戲（88 Fortunes 106 款、Lightning Link 114 款，依大廳順序），**雙擊「錄」勾選**就能錄。
- 上方 **搜尋** 框打幾個字就能找到；點一款會在下方顯示它的大廳縮圖
- app 更新、出了新遊戲 → 按 **🔍 掃描大廳找新遊戲**（約 5~8 分鐘，期間不要操作那台模擬器），清單裡沒有的會自動加入（不勾選）。
  名字是讀圖猜的，請雙擊「名稱」改成正確的；如果加進來的是重複或不是遊戲，選它按「刪除」
- 名稱後面原本標「(?)」的幾款（例如 Dancing Drums Tower、Jade Eternity、Wild Tooth）標題被擋住，名字可能不準

## 手動新增 slot（清單裡真的沒有時）
1. 在模擬器裡把大廳滑到 **看得到那個 slot 縮圖** 的位置
2. 按 **＋ 新增 slot** → 確定 → 在截圖上 **拖曳框住縮圖的圖案** → 輸入名稱 → 儲存
3. 選它按 **測試尋找**：找到會跳出標了黃圈的截圖；找不到 → 框小一點、避開會動的特效

## 卡在新的彈窗？自己加範本（不需要 AI，錄製中也可以）
1. **＋ 從目前畫面框選**（彈窗還在畫面上時）或 **＋ 從截圖檔框選**（用影片旁 `_snaps\` 裡 `esc_` / `off_` 開頭的截圖）
2. 框住要點的東西，選類型：
   - **X 關閉鈕**：存進所有 app 共用的 X 庫（`core\x_library\`），框整顆 X 含外圈
   - **按鈕**（例如 Great、OK、Collect）：只用在這個 app，框文字＋按鈕底色
3. 儲存後程式會馬上在那張圖上測一次找不找得到；正在錄的工作 5 秒內就會開始用
> ⚠ 不要框購買、看廣告、付費解鎖的按鈕。

## 自動處理了哪些狀況
| 狀況 | 處理 |
|---|---|
| 廣告 / Play 商店 / 其他 app 搶前景 | 返回鍵，不行就重開 app |
| 有 X 的彈窗 | 點 X（含轉 90 度的橫式彈窗；被遮住變暗的 X 不算） |
| 沒 X 的彈窗 | 已知按鈕範本 → 亮著的 SPIN → OCR 讀按鈕字（只點 CONTINUE / CLAIM / GREAT 之類）→ 點畫面中央 |
| 有價格 / BUY / UNLOCK / WATCH 的畫面 | **整頁只允許點 NO THANKS / LATER / CLOSE**，絕不點購買 |
| 掉回大廳 | 重新找 slot 進入、調回最低押注 |
| 畫面凍結 / 卡住 / 點中央 10 次沒反應 | 返回鍵 → 3 次無效就重開 app |
| 押注被改（升級、特色遊戲後） | 每 10 分鐘讀一次押注，變了就調回最低 |
| 金幣用完 | Lightning Link：清 app 資料換新訪客帳號後接著錄。88 Fortunes：**自動建一台全新模擬器**（`SR_` 開頭）→ 裝 app → 新手流程 → 練到約 5 級解鎖 Dragon Trio → 接著錄（約 15 分鐘）；失敗就停止並保存影片 |
| scrcpy 錄影中斷 | 自動開新段落接著錄，最後合併成一支 |

> 安全建議：模擬器的 Google 帳號 **不要綁定付款方式**。
> 換新訪客帳號時，程式會代為點選遊戲的「同意服務條款」（Lightning Link 的 I AGREE、88 Fortunes 的 ACCEPT）。

## 新增 app（需要開發者擴充）
每個 app 是 `apps\<id>\` 一個資料夾：`profile.json`（package、SPIN / 押注座標、餘額 / 押注數字位置 `meters`、範本名稱、大廳捲動、重置方式）
＋ `tpl\`（介面範本）＋ `slots\`（slot 縮圖）＋ `slots.csv`。新 app 需要實機走一遍收集範本。

## 檔案
```
run.bat / install.bat / config.json     啟動、安裝、本機設定
gui.py                                  主程式
core/   config device vision ocr app record batch analyze pack   共用引擎
core/x_library/                         所有 app 共用的 X 關閉鈕範本
apps/<id>/profile.json tpl/ slots/ slots.csv        每個 app 的設定與範本
videos/<id>/                            輸出影片與統計
logs/                                   工作紀錄（job_*.json / job_*.log）
```
命令列（進階，在 SlotRecorder 資料夾）：
`python -m core.batch --app lightning_link --slots bzzf_golden5 --emu 1`　`python -m core.analyze 影片.mp4`　`python -m core.pack`

## 改程式之前 / 之後（測試）
- `run_tests.bat`:單元測試(不需模擬器,1 秒)+ 統計回歸比對。
- 要改 `core\analyze.py` 的記帳邏輯時:先 `python -m core.regress snapshot` 記下現在的數字,改完跑 `python -m core.regress`,會列出哪幾支影片的數字變了(用各影片快取的餘額序列重算,不讀 mp4)。
- 進階設定(特色跳過秒數、讀取率門檻、截圖保留天數…)的預設值與說明都在 `core\config.py` 的 `ADVANCED` 表;要改就把該鍵寫進 `config.json`。

## 複製到別台電腦
按 **打包帶走**，把 zip 複製過去解壓，跑一次 `install.bat`，再 `run.bat` → 準備模擬器 → 環境檢查。資料夾路徑可以有中文。

## 包你發娛樂城（v1.6.0 起）
- 中文介面：關彈窗會認中文按鈕（領取、確定、取消、否…），**付費相關字（購買、儲值、NT$、TWD、首儲、禮包、商城、綁定、離開 / 退出遊戲…）出現的畫面只會按否定的按鈕**；
  同一個對話框有「確定」和「否 / 取消」時一律按否定的那個
- 訪客只能玩**體驗廳**（金幣 1:100），新帳號約 15.7 萬體驗廳金幣；押注只有一顆循環按鈕（例 50→100→250→500→1000→50），程式會轉到最低
- 每款遊戲第一次點會先下載，程式會等下載完再點一次；選台畫面會先切到體驗廳再按「馬上玩」
- 遊戲清單 109 款（老虎機分類），名稱是看圖辨識，標「(待確認)」的看不清楚或可能重複，可在 GUI 雙擊名稱修改；影片檔名用代號（例 `bnf_026`）
- **訪客帳號綁在模擬器上**（清 app 資料會登回同一個帳號），沒錢時跟 88F 一樣自動建新模擬器
- 每週四 09:30~12:00 例行維護，這段時間無法錄
- **自動加速**：進遊戲後把速度鍵（閃電）切到最快，每分鐘約 20 局（一般速度約 10 局）；只改動畫長短，不影響結果。設定可關閉
- **包你發必須從 Google Play 商店安裝**（有 Play 防側載保護，複製安裝打不開）。每一台要錄包你發的模擬器，都要先登入 Google 帳號、從 Play 商店裝一次；
  因此包你發**不能**用「自動新建模擬器」補錄（新模擬器沒帳號）。工具偵測到被導向 Play 商店時會停止並說明。Lightning Link / 88 Fortunes 沒這個限制，可自動複製安裝

## 已知限制
- **88 Fortunes 的訪客帳號綁在裝置上**：清 app 資料、換 Android ID / IMEI / 型號、移除 Google 帳號都會登回同一個帳號，只有全新模擬器才是新帳號。
  所以 88F 沒錢時程式會建新模擬器（名稱 `SR_日期時間`）。**程式只會刪除自己建的 `SR_` 模擬器**，你原本的模擬器只會被關機、不會被刪（主帳號保留）。
  不想自動建新模擬器：設定 → 取消勾選「…沒錢時自動建一台全新模擬器」，沒錢就停止錄影。
  每台模擬器約占 5 GB 硬碟；app 安裝檔存在 `apk_cache\`，**打包時會一起帶走**（Lightning Link + 88 Fortunes，約 500 MB），換電腦可自動安裝；
  有 Play 商店驗證的 app（如包你發）側載無效，打包會自動略過，需在該台登入 Play 手動安裝。
- **遊戲保持最新版（避免卡在「請更新」）**：挑一台當「主更新台」（例 index 0，已登入 Google 帳號），在它的 Play 商店開啟
  「自動更新應用程式→透過任何網路」（頭像→設定→網路偏好設定）。工具錄製前會自動把主更新台的最新版重新打包進 `apk_cache`、
  再升級其他台，所以只要主更新台偶爾開著讓 Play 更新，其他台就會自動跟上。若打包的版本也過舊（連 Play 都要求更新），先讓主更新台更新完再錄。
- 範本是像素比對，模擬器解析度必須是 1280×720 / 240 DPI；app 改版換 UI 時可能要補範本。
- 定時開始需要 GUI 視窗開著；電腦重開機後**排程**不會保留（已經開始的錄製會自動接續）。
